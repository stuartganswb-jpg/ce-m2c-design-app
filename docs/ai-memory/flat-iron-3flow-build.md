**Part decode (`FI…` codes), confirmed by the user:**
- `FIVBP` (Vertical Backplate) / `FIHBP` (Horizontal Backplate) — orientation of the plate; **both WALL-mounted**. `FIM…` prefix = **Mini** (smaller, alt size). So V/H/Mini are backplate STYLE options, NOT the wall/ceiling/end split.
- Wall/Ceiling/End split = pole-arm + end-adapter family: `FIW…` (Wall: FIWPBA, FIWERA), `FIC…` (Ceiling: FICPBA, FICERA), `FIIM` (Inside Mount = end bracket, L/R only). FIIM can pair with a wall OR ceiling center bracket depending on mount height — decided in the Vision canvas.
- `FIPBHS` = hidden rear-attach part: **hide from 3D view, but include in BOM 1pc per bracket**.
- Brackets at L/C/R (Z axis): FIHBP/FIMHBP ×3 (1/pos), FIVBP/FIMVBP ×6 (2/pos), end pieces (FIWERA/FICERA/FIIM) are L/R pairs (Mirror suffix), pole + Rec Ring shared.
- **Fab behavior:** wall = real projection (4.25 std / 4.125 mini); ceiling = projection 0 (formula drops out); end = projection 0 + INSIDE mount → IM-deduct (bracket thickness). The Vision tool already handles all three via per-end OPEN/INSIDE/CEILING mount + projection — no fabMountType field needed.

**Two features this drove (both built):**
- **Per-option projection** (PROD, PR #9): a STYLE_SWAP option carries its own `projection` ("Proj″" field by price/Z in builder); when selected, Vision's `engData.proj` switches to it (overriding the flow preset) WITHOUT changing the 3D rendering. For collections that vary only by projection. Vision hook: effect on `dynamicConfigParams[bracketStep.id]` reads the matched option's projection. Backward-safe.
- **Flow-level Hide Geometry** (on preview branch `cpq-flow-hide-clusters`, awaiting user verify): `flow.hiddenClusters` (cluster-id list) picked in the flow's master-assembly settings; CPQTab `visibilityOverrides` forces those clusters' nodes hidden. So the wall flow hides ceiling+end clusters and renders only wall brackets. KEY INSIGHT: CPQ 3D defaults every mesh VISIBLE and only toggles meshes referenced by a step's geometryMap — so a flow does NOT hide other configs' geometry unless explicitly told to (this feature).
